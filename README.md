# Scrap Hopper
## A Short Video Game by Miah Terrazas

## itch.io
https://tan-miya.itch.io/scrap-hopper

## Setup
*You play as a constantly jumping machine in a cave, always needing fuel to keep going to collect gemstones. Collect ten gemstones to win, but be sure to avoid enemies!*
**Made with Unity.**

## Features
- Doodle Jump inspired gameplay
- Player Health
- Static and Moving Enemies
- Item Collection
- Custom GFX
